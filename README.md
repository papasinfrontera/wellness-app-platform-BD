# WELLNESS APP Platform — nuevo desarrollo

Repositorio **independiente** para la reconstrucción tecnológica de WELLNESS APP con Next.js + TypeScript, Supabase PostgreSQL, Storage, importaciones PDF/WHOOP, Clinical Rules Engine y WELLNESS Intelligence con base científica RAG.

## Versiones y ramas

- `main`: documentación inicial del nuevo proyecto.
- `sprint-6-1-foundation`: código inicial de la nueva aplicación, tipos TypeScript, endpoint técnico y borrador del esquema PostgreSQL.

## Preservación de la demo

La demo actual está conservada en https://github.com/papasinfrontera/wellness-app-demo y publicada en https://wellness-app-demo-sprint1-papasinfronteras-projects.vercel.app . **No desplazar ni reemplazar el proyecto Vercel actual durante esta migración.**

## Privacidad y seguridad

El titular ha autorizado explícitamente conservar sus datos personales en un repositorio público. Esto NO autoriza publicar credenciales, tokens de servicios ni datos de terceros. La nueva plataforma multiusuario debe usar almacenamiento privado y controles de acceso para datos de pacientes, independientemente de esta autorización específica para los datos propios del titular.
